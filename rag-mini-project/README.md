# RAG Study-Guide Assistant (Coursera mini project)

A complete, modular Retrieval-Augmented Generation (RAG) system in Python:
**ingestion → extraction → cleaning → chunking → embeddings → FAISS index → query embedding → top-k retrieval → prompt assembly → generation → answer with source references**,
with a Streamlit UI, an automated test suite (pytest) and a reproducible evaluation.

> **Honest status.** The default configuration runs fully offline: embeddings are a locally fitted TF-IDF + SVD (LSA) model and the "generator" is an *extractive* (non-LLM) answerer.
> A pretrained embedding model (sentence-transformers) and LLM providers (Anthropic, Ollama) are implemented but **were not executed** during development (no model download / API / server was available).
> The knowledge base is **synthetic** (original sample documents written for this project). All numbers in `docs/` come from executed runs (`artifacts/`).

| `scripts/` | `build_index.py`, `run_evaluation.py`, `run_experiments.py`, `run_threshold_sensitivity.py`, `build_sample_kb.py`, `make_diagrams.py`, `build_docs.py`, `check_pages.py`, `package_submission.py`, `start_app.sh`, `stop_app.sh` |

| `artifacts/` | Evidence from executed runs: `evaluation/`, `experiments/`, `tests/`; `index/` is generated and git-ignored |

## Prerequisites
* Python 3.10+ (developed and tested on **Python 3.13.16**, Linux). No GPU, no paid API required.
* Internet only for `pip install`. (LibreOffice is needed only for `scripts/check_pages.py`.)

## Setup
```bash
python -m venv .venv
source .venv/bin/activate            # Windows: .venv\Scripts\activate
pip install -r requirements.txt      # or requirements-lock.txt for the exact tested versions
cp .env.example .env                 # optional; defaults work without it
python scripts/build_index.py        # builds artifacts/index (≈2 s)
```

## Run
```bash
streamlit run app.py                 # open http://localhost:8501
# or, background start / stop:
scripts/start_app.sh                 # builds the index if needed and starts the app (PORT=8501 by default)
scripts/stop_app.sh                  # shutdown
```
In the UI: ask a question; read the answer; inspect the **Sources** table (file, page, section, similarity, cited yes/no) and the expandable passage text; check **diagnostics**; use the sidebar to change top-k, the generator, restrict to documents, **upload** new PDF/DOCX/MD/TXT files (saved to `data/knowledge_base/` and re-indexed) or **Rebuild index**.

Command line:
```bash
python scripts/run_evaluation.py     # 34 cases -> artifacts/evaluation/eval_results.{json,csv}
python scripts/run_experiments.py    # chunk size x top-k x embedder sweep -> artifacts/experiments/
python -m pytest -q                  # 75 tests
```

## Configuration (environment variables or `.env`; see `.env.example`)
| Variable | Default | Meaning |
|---|---|---|
| `RAG_CHUNK_SIZE` / `RAG_CHUNK_OVERLAP` | 500 / 100 | chunk size and overlap in characters |
| `RAG_EMBEDDER` | `lsa` | `lsa`, `tfidf`, or `sentence-transformers` |
| `RAG_TOP_K` | 4 | passages retrieved |
| `RAG_MIN_SCORE`, `RAG_MIN_COVERAGE` | 0.15, 0.34 | abstention thresholds (extractive generator) |
| `RAG_LLM_PROVIDER` | `extractive` | `extractive`, `anthropic`, `ollama` |
| `ANTHROPIC_API_KEY` | – | **environment only**, never committed; needed for `anthropic` (paid API) |
| `RAG_KB_DIR`, `RAG_INDEX_DIR` | `data/knowledge_base`, `artifacts/index` | locations |

**Optional back-ends (untested here):** `pip install -r requirements-optional.txt`, then `RAG_EMBEDDER=sentence-transformers` (downloads a model on first use; rebuild the index afterwards) or `RAG_LLM_PROVIDER=anthropic` (+ `ANTHROPIC_API_KEY`) / `ollama` (local server). If a provider is unavailable the app shows a clear error; it never silently switches provider.

## Adding documents / updating the index
Put `.pdf`, `.docx`, `.md`, `.txt` files into `data/knowledge_base/` (or upload in the UI) and run `python scripts/build_index.py` (or press *Rebuild index*). The manifest stores SHA-256 hashes of every file; the UI warns when the index is stale. Updates are full rebuilds. Failed files (empty, corrupted, unsupported) are listed in the ingestion report and skipped.

## Rebuilding the deliverables
```bash
python scripts/build_sample_kb.py && python scripts/build_index.py
python scripts/run_evaluation.py && python scripts/run_experiments.py && python scripts/run_threshold_sensitivity.py
python -m pytest -q -rA --junitxml=artifacts/tests/junit.xml > artifacts/tests/pytest_output.txt
python scripts/make_diagrams.py
# edit docs/team_info.json (names, roll numbers), then:
python scripts/build_docs.py && python scripts/check_pages.py
python scripts/package_submission.py   # -> Coursera_<roll1>_<roll2>_<roll3>.zip
```

## Troubleshooting
* *"The index has not been built yet"* → run `python scripts/build_index.py`.
* *"Knowledge-base files ... changed since the index was built"* → press **Rebuild index**.
* `faiss` import error → `pip install faiss-cpu`; on very old CPUs/platforms use a conda build.
* A file shows `failed` in the ingestion report → read its message (scanned PDFs have no extractable text; there is no OCR).
* `ANTHROPIC_API_KEY is not set` → export it in your shell or `.env`, or use `RAG_LLM_PROVIDER=extractive`.
* Port busy → `PORT=8600 scripts/start_app.sh` or `streamlit run app.py --server.port 8600`.
* Security note: `embedder.joblib` is a pickle; only load index folders you built yourself.

## Limitations
Tiny synthetic corpus; author-written evaluation; LSA has little semantic knowledge; the extractive generator cannot paraphrase or synthesise; no OCR; English only; neural embeddings and LLM generation untested. See `docs/` for details.
