# Design decisions (Phase 1 record)

* **Guideline source.** `coursera project.docx` was initially unavailable, so requirements were first taken from the task prompt; the document was uploaded afterwards and verified to list the same seven components and limits.
* **Topic.** "RAG Study-Guide Assistant": question answering over a small synthetic corpus about RAG itself. Chosen because facts and relevance labels can be stated objectively, no private/licensed data is needed, and it allows unanswerable near-topic questions and a poisoned document.
* **Corpus.** No external documents were reachable (only PyPI was reachable from the sandbox), so original sample documents were written for the project and are labelled synthetic. No source URLs or access dates exist because nothing was downloaded.
* **Embeddings.** HuggingFace was unreachable → default is a locally fitted TF-IDF + SVD (LSA) embedder. sentence-transformers is implemented behind the same interface but was not executed. No result is attributed to it.
* **Generator.** No LLM key/server available → default is an extractive, offline generator (quotes retrieved sentences, abstains below thresholds). Anthropic and Ollama providers are implemented, share the same structured prompt, and were not executed. The provider is shown with every answer; there is no silent fallback.
* **Vector store.** FAISS IndexFlatIP over L2-normalised vectors (exact cosine). Persisted with a chunk table and manifest of file hashes; updates are full rebuilds (LSA must be refitted).
* **Chunking.** Sentence-aware, 500 chars / 100 overlap, per page/section for exact metadata.
* **Evaluation.** Rule-based relevance labels (document + evidence phrase), keyword-based correctness, lexical faithfulness; no LLM judge. Abstention thresholds (0.15, 0.34) were fixed before the first evaluation run and not changed afterwards; a post-hoc sensitivity sweep is reported separately.
* **Diagrams.** PNGs are generated by `scripts/make_diagrams.py` (matplotlib); `.mmd` files are hand-written Mermaid equivalents that are not rendered by any script.
* **Documents.** DOCX built with python-docx from the real result files; page counts measured by converting to PDF with LibreOffice (Word may differ slightly; every limited document has spare room on its last page).
